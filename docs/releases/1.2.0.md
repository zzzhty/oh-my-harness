# OMH 1.2.0

Source content version prepared on 2026-11-14. A release is a tagged source
checkout. This record does not assign a tag SHA or an `omh-v1.2.0.ref` asset;
those are created at publication.

An earlier 1.2.0 tag, release, and assets were deleted. The retracted changelog
entry keeps its original wording. This version is a new source payload.

## Changes from 1.1.1

- Add three explicit-only skills. `repo-lessons-lint` is in `maintenance`.
  `blast-radius` and `create-verification-skill` are in `workflow`. They are
  adapted from pstack under the MIT License, Copyright (c) 2026 Lauren Tan.
  Each skill carries a `NOTICE.md`.
- Fold `principle-attack-the-premise` into `mattpocock-skills:diagnosing-bugs`.
  The skill's invocation policy is unchanged. Attribution is in that skill's
  `NOTICE.md` and the plugin README.
- The hub catalog is 32 skills, including the existing 20 Matt skills.
- Distribution and CLI work landed since the 1.1.1 reissue is listed under
  `1.2.0 — 2026-11-14` in [CHANGELOG.md](../../CHANGELOG.md).

`content-manifest.json` `releaseVersion` is `1.2.0`. Plugin manifests use
`1.2.0+codex.<generation>` from `scripts/update_plugin_generations.py`.
No runtime binding was added.

## Validation and distribution

The version commit runs the repository gates: the unittest suites in the
[validation entry point](../../README.md#versions-and-validation),
`python scripts/check_architecture.py`, `python scripts/check_plugin_generations.py`,
`git diff --check`, and `python scripts/check_standalone_distribution.py`.
The content CI job runs those checks on Linux, macOS, and Windows with Python
3.11 and 3.12.

Installation stays `python -m omh` from a verified source tree. Publication
does not migrate an existing Home installation.
