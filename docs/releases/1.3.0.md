# OMH 1.3.0

Source content version prepared on 2026-11-19. The skill catalog is the tree at
`167ac46`. This commit advances the source version and distribution identity,
and publication tags it `v1.3.0`. That tag is the repository's first GitHub
Release. The release asset `omh-v1.3.0.ref` holds `git rev-parse v1.3.0^{}`.

## Changes from 1.2.0

- Load `tdd` from `implement` only when the user or agreed spec requires
  test-first work. Ordinary implementations still verify changed behavior.
- Remove the standalone `pr` skill. Writing a pull request description is
  ordinary model work.
- Replace `mattpocock-skills:ask-matt` with explicit-only
  `workflow:skill-guide`. It chooses from skills the active harness already
  exposes, and it can recommend no skill.
- Remove `grill-me`. An interview uses `grilling`. Fold
  `improve-codebase-architecture` into `codebase-design` as an explicit
  architecture review.
- Remove the callable `workflow:scope-discipline` skill. Its necessity gate
  stays a long-running-goal reference. Compress `orchestrate-subagents` to its
  assignment contract.
- Compress `grill-with-docs`, `to-spec`, `implement`, `research`,
  `writing-for-agents`, and `handoff` without removing those entries.
- The hub catalog is 28 skills: maintenance 4, workflow 8, and 16 Matt skills.
- The architecture check resolves `--harness` choices independently, including
  when a short flag precedes `--harness`.

## Validation and distribution

The version commit runs the repository gates: the unittest suites in the
[validation entry point](../../README.md#versions-and-validation),
`python scripts/check_architecture.py`, `python scripts/check_plugin_generations.py`,
`git diff --check`, and `python scripts/check_standalone_distribution.py`.
The content CI job runs those checks on Linux, macOS, and Windows with Python
3.11 and 3.12.

Host installation is `curl` of `install.sh`, which resolves `releases/latest`.
Installation from a checkout stays `python -m omh`. Publication does not
migrate an existing Home installation.
